# Security Audit Team

Audit practice: playbook, contest notes, reports and a scanner.

## What this is

A playbook for auditing smart contracts, notes on audit contests, triage reports on our own contracts, a small Python scanner, and a Foundry puppy-raffle practice repo (vendored without its git history; run `forge install` after cloning to fetch `lib/`).

## Status

Practice repo. The puppy-raffle Makefile contains Foundry Anvil's well-known public default test key — a worthless standard fixture, not a real secret.
